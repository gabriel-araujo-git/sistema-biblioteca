# Sistema de Biblioteca Pública

Este projeto contém o **projeto conceitual e lógico** de banco de dados para uma biblioteca pública. Ele inclui diagramas ER, modelo lógico relacional e regras de negócio.

## Funcionalidades

- Registro de livros com título, autor, ano e exemplares disponíveis
- Cadastro de autores e suas obras
- Gestão de membros da biblioteca
- Controle de empréstimos e devoluções
- Organização de livros por categorias

## Diagramas e Modelos

Os diagramas e tabelas estão disponíveis no arquivo HTML do projeto.
